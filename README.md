# Strong_Password_Generator
🔐 Password Generator using Python

A simple GUI-based Password Generator built with Python, Tkinter, and the Random library. It generates random and customizable passwords based on the user's selected length and character types.

Features
🔑 Generate random passwords
🔢 Include numbers
🔣 Include special characters
🔤 Include letters
📋 Copy generated password
🖥️ Simple Tkinter GUI
Technologies Used
Python
Tkinter – Graphical User Interface
Random – Random password generation
Run the Project
python password_gui.py
